PROJECT 01 · DEEP LEARNING

Visiona AI

A real-time assistive navigation system for blind and visually impaired users. It reads a live camera feed, estimates how far away things are from a single RGB camera, and gives short spoken guidance, hands-free, with offline fallbacks.

PythonYOLOv8Depth Anything V2PyTorchOpenCVLangChain
camera→YOLOv8→depth→ByteTrack + Kalman→TTC→voice
View on GitHub
  • Perception. YOLOv8 detects 80+ object classes while Depth Anything V2 turns a single RGB camera into metric distance, across multiple camera feeds.
  • Threat assessment. Combines distance, approach speed and time-to-collision, with ByteTrack, Kalman filtering and a priority queue. A 7-second penalty heatmap suppresses false and repetitive proximity alerts.
  • Zero-shot custom objects. MobileNetV3 embeddings with cosine similarity swap a generic label such as "person" for a saved name on the fly, with no fine-tuning and no catastrophic forgetting.
  • Voice agent. Push-to-talk commands go to an LLM agent that sets goals, searches memory and requests walking directions.
PROJECT 02 · GENERATIVE AI

ResearchPilot AI

A research intelligence platform that reads academic papers and answers questions with evidence and source citations, so you can see where each claim came from.

PythonFastAPILangChainChromaSentenceTransformersMySQL
papers→embeddings→Chroma + MySQL→retrieve→LLM + citations
View on GitHub
  • Hybrid retrieval. MySQL holds structured paper metadata while Chroma vector search over SentenceTransformers embeddings finds semantically relevant passages.
  • Grounded answers. RAG with semantic search and LLMs returns evidence-based answers that cite their sources.
  • Research analysis. Paper comparison, methodology extraction, citation-aware retrieval and research-gap identification, to surface relationships across large collections of papers.
PROJECT 03 · NLP

News Summarization System

Paste in any news article URL and get a summary two ways: extractive for speed and offline use, abstractive for a more human-sounding read.

PythonBARTTransformersScikit-learnNLTKBeautifulSoup
URL→scrape→TF-IDF/BART-large-CNN→summary
View on GitHub
  • Two independent pipelines. Extractive and abstractive summaries, with a CLI flag that skips the heavy model for roughly 5× faster output.
  • Abstractive. The pretrained BART-large-CNN model, run through Hugging Face Transformers, writes summaries for articles of any length.
  • Extractive. TF-IDF sentence ranking with NLTK tokenization and BeautifulSoup4 scraping, built on Scikit-learn so it works offline with no heavy dependencies.
